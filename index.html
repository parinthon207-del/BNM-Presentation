🏗️ โครงสร้างคลาสในระบบ (7 Classes)

ออกแบบตามหลักการ OOP รวมทั้งสิ้น 7 คลาสหลัก แบ่งหน้าที่ทำงานอย่างชัดเจน:

1. Expense Parent Class

คลาสแม่สำหรับเก็บข้อมูลพื้นฐานของทุกรายการใช้จ่าย

2-4. Need / Want / Impulse Expense Subclasses

คลาสลูกที่สืบทอดคุณสมบัติเพื่อจัดการประเภทรายจ่ายเฉพาะ

5. BudgetTracker

จัดการคำนวณงบประมาณ รายรับ-รายจ่ายคงเหลือ

6. FinancialAnalyzer

ประมวลผล สถิติ และวิเคราะห์ข้อมูลไดนามิก

⚙️ การประยุกต์ใช้หลักการ OOP (OOP Mapping)

1. Encapsulation (การซ่อนข้อมูล)

ซ่อน Attribute ภายในคลาสด้วย # (Private Field) ใน Expense.js และเข้าถึงผ่าน Getter Methods เท่านั้น

class Expense { #amount; constructor(amount) { this.#amount = amount; } getAmount() { return this.#amount; } }

2. Inheritance (การสืบทอด)

คลาส ImpulseExpense สืบทอดโครงสร้างมาจากคลาสแม่ Expense ด้วยคีย์เวิร์ด extends

class ImpulseExpense extends Expense { ... }

3. Polymorphism (การ Override)

คลาสลูกทำการ Override Method getDetails() เพื่อแสดงผลข้อความเตือนสติที่ต่างกันไปตามประเภท
