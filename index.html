ซ่อนข้อมูลด้วย private field

ตัวแปร #monthlyBudget, #currentBalance, #daysRemaining ประกาศเป็น private field (บรรทัด 2–4) เข้าถึงจากภายนอกคลาสโดยตรงไม่ได้

เข้าถึงผ่าน method เท่านั้น

ต้องเรียกผ่าน getCurrentBalance(), deduct(), addBack() ซึ่งเป็น method สาธารณะที่ควบคุมว่าข้อมูลจะถูกอ่าน/แก้ไขอย่างไร ป้องกันค่าผิดพลาดจากภายนอก

คลาสแม่ - คลาสลูก

Expense เป็นคลาสแม่ที่เก็บคุณสมบัติร่วมของรายจ่ายทุกประเภท (จำนวนเงิน โน้ต วันที่)

extends ในบรรทัดประกาศคลาส

EssentialExpense, RewardExpense และ ImpulseExpense ใช้ extends Expense เพื่อสืบทอด method และ property ทั้งหมดจากคลาสแม่ แล้วเพิ่มพฤติกรรมเฉพาะของตัวเอง

🎭 Polymorphism

1  rawList.map(item => {
2    if (item.categoryLevel === 'ESSENTIAL')
3      exp = new EssentialExpense(...);
4    else if (item.categoryLevel === 'REWARD')
5      exp = new RewardExpense(...);
6    else exp = new ImpulseExpense(...);
7  });
UIManager.js — renderExpenseList() 
1  expenses.map(exp => {
2    const badge = exp.getCategoryBadge();
3    return `${badge.icon} ${exp.getNote()}`;
4  });

Method Overriding

ทั้ง 3 คลาสลูก override getCategoryBadge() ให้คืนค่าไอคอน สี และ label ต่างกันไปตามประเภทของตัวเอง

เรียกใช้แบบเดียวกัน ได้ผลต่างกัน

UIManager และ FinancialAnalyzer เรียก exp.getCategoryBadge() โดยไม่สนใจว่า exp เป็น subclass ไหน — โค้ดชุดเดียวทำงานถูกต้องกับทุกประเภทรายจ่าย
